# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public GitHub issues, discussions or pull requests.

Report them privately on GitHub instead: open the [Security tab](https://github.com/ConvertAPI/convertapi-library-dotnet/security) of this repository and click "Report a vulnerability", or go straight to [the report form](https://github.com/ConvertAPI/convertapi-library-dotnet/security/advisories/new). Only you and the maintainers can see the report.

Please include:

- the version of the ConvertApi NuGet package and of .NET you use;
- the steps to reproduce the issue, or a proof of concept;
- what an attacker could do with it.

We will confirm that we received your report and keep you updated until it is fixed. Please give us reasonable time to release a fix before you disclose the issue publicly.

You can use the same private route if you are not sure whether the issue is in this SDK or in the ConvertAPI service itself.

## Supported versions

Security fixes are released in the latest version of the [ConvertApi package on NuGet](https://www.nuget.org/packages/ConvertApi). Please check that the issue still occurs with the latest version before you report it.
